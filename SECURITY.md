# Security

Please report security vulnerabilities in Perfect Streamer privately to **support@pstreamer.tv** with the subject
"Security", not in public issues or discussions.

Include the product version (`pss --version`), the operating system, and the steps to reproduce. We answer within a few
working days and tell you when a fixed version is available.

Packages from `repo.pstreamer.tv` are signed with the key **Perfect Streamer Repository &lt;support@pstreamer.tv&gt;**,
fingerprint `E391 9454 BFD9 DEA4 6CDE C886 5BDD 7AE6 BEB5 D084`
([public key](https://repo.pstreamer.tv/pub/RPM-GPG-KEY-pstreamer)).
